## Production pipeline (every asset, no exceptions)
1. **Brief** — what surface, which storyboard/state, which bible blocks apply.
2. **Registry check** — does an equivalent asset exist? (`ASSET-REGISTRY` + `CAMPAIGN-LIBRARY`). Reuse beats regenerate.
3. **Compose** — prompt assembled ONLY from `HIGGSFIELD-PROMPTS.md` blocks + canonical reference media.
4. **Preflight** — `get_cost: true`; one test render before any batch; batches >300 credits need founder go.
5. **Score** — `CONSISTENCY-SCORING.md` gate against the reference photos. Fail → retake or stop; never ship a sub-threshold Kai.
6. **Approve** — founder sign-off for canonical/master assets and anything public (🟡).
7. **Register** — `ASSET-REGISTRY.md` entry: ID, job_id, score, cost, approved use.
8. **Compliance** — anything public passes `/compliance-review` (storyboards reviewed at board stage, before render spend).
