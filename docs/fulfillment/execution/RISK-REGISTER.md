# RISK-REGISTER.md — Severity-Ranked Register

Consolidation only. Aggregates every domain doc's risk section plus the coordinator's cross-cutting tensions from `EXECUTION-PLAN.md`. Ranked blocking-first. Every row cites its source.

## Severity legend

| Grade | Meaning |
|---|---|
| **A — BLOCKING** | Halts all downstream work in its lane until resolved; no engineering workaround exists |
| **B — HIGH** | A live/present defect, or a large but resolvable completeness gap; urgent, does not block everything |
| **C — MEDIUM** | Real but contained; standard review cadence handles it |
| **D — LOW / DEFERRED** | An open question on unscheduled/future work; does not block v1 |
| **E — INFORMATIONAL** | A copy/labeling/product decision; low technical risk, needs a founder/CCO call before ship, not before build |

Where a source doc uses its own HIGH/MEDIUM/LOW label (e.g. `WALLET-VC-RUNTIME-PLAN.md` §6), that label is preserved in the Note column alongside this register's A–E translation — the two scales measure different things (the source's label is severity-if-it-occurs; this register's grade also weighs how blocking the item is to the September 1 plan) and are not in conflict.
