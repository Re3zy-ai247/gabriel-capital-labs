# Founder Intelligence Layer — systems that augment Rey, never replace him

Status: partially LIVE (the AIOS fleet), partially DESIGNED. **Principle: systems prepare, Rey decides.** Every component below ends in a human decision surface, not an autonomous action — the decision-rights framework (AIOS charter §2) is the constitution of this layer. Nothing here dilutes the founder's taste, voice, or authority; it multiplies his hours.

## The layer, mapped (existing → extended)
| Capability | Exists today (VERIFIED) | Extension (DESIGNED) |
|---|---|---|
| **Research copilot** | `/gcl-research` (cited consumer-credit landscape monitoring); Brief ingestion pipeline | Cross-domain briefs as new products scope (Year 1.5); competitive teardowns on demand; every claim cited or labeled |
| **Strategic advisor** | `/gcl` Chief of Staff (routing, daily brief, backlog, Top-10) + AIOS charter decision gates | **Decision journal**: every 🟡/🔴 decision logged with context, options, choice, expected outcome → quarterly calibration review ("what did we believe vs what happened") — the founder's judgment, instrumented for HIS learning |
| **Creative director** | This session's pattern: Claude-as-CD over the Creative OS (bibles make direction deterministic) | Standing: any session can direct production without re-deriving taste — the bibles ARE Rey's externalized taste; drift caught by scoring gate |
| **Product review** | Five-review gate + Founder's Standard (Art. XI) + `/compliance-review` | Pre-review packs: before Rey reviews anything, the system assembles the evidence (gate answers, moat claim, delight items, compliance notes) so his 5 minutes are judgment, not archaeology |
| **Executive dashboards** | `/admin` suite (4 dashboards, honest metrics) + AIOS `DASHBOARD.md` | Weekly founder brief (auto-assembled from BI + backlog + decision journal): 1 page — what moved, what's blocked on you, what needs a decision, what compounds. The "blocked on you" section is the highest-leverage list in the company |
| **Company memory** | The `.ai/` OS + AIOS knowledge graph + cross-session memory + ADRs | The memory is already the moat (#7). Extension: quarterly consolidation pass (dedupe, prune stale, promote lessons) — scheduled, not heroic |

## Boundaries (permanent)
- Systems draft; **Rey approves everything public, financial, legal, or brand-canonical** (decision rights stand regardless of how good the drafts get).
- The founder's VOICE is never synthesized without the CONTENT-PRODUCTION-PIPELINE consent gates; "Founder Notes" ghost-drafts are always Rey-edited before publish.
- Augmentation is measured by ONE metric: founder hours redirected from preparation to decision/creation. If a system adds review burden instead of removing prep burden, it fails the Founder's Standard and gets simplified.
- Anti-pattern watchlist: dashboards nobody reads (kill quarterly), briefs longer than a page, "advisors" that hedge instead of recommending. Every advisor surface must END with a recommendation and its strongest counter-argument — Rey gets a position to react to, not a survey.

## Build order (fits the platform roadmap)
Year 1: decision journal (a file convention + `/gcl` habit — nearly free) → weekly founder brief (assembled from existing sources) → pre-review packs. Year 2: calibration reviews; cross-product memory partitions as product #2 arrives. All of it runs on the existing AIOS + `.ai/` rails — this layer needs almost no new infrastructure, only disciplined use of what exists.
