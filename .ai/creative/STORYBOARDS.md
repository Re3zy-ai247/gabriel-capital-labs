# Commercial Storyboard Library

Every video/commercial starts as a storyboard here, passes `/compliance-review` **at board stage** (before any render spend), then renders per the pipeline (`README.md`). Hybrid law from CAMP-001 stands: real UI captures + composited real logo; AI renders only for Kai and environments — models never redraw brand marks or interface text.

## Master template (15–60s spots)
| Beat | % of runtime | Content | Kai's role |
|---|---|---|---|
| 1. Hook | 0–15% | the felt problem (confusing report, stalled dispute) — never fear-mongering | ears perk (STATE-03): Kai noticed |
| 2. Turn | 15–30% | CreditVector appears — INK STUDIO world | Kai walks in (SHOT-F) or head tilt |
| 3. Product proof | 30–70% | REAL UI captures: upload → analysis → letter → tracking | Kai gazes at UI (SHOT-E, STATE-05/06) |
| 4. Confidence | 70–85% | education-first claim, disclaimer beat ("No outcome is guaranteed" — visible, not buried) | calm thinking → subtle nod |
| 5. CTA | 85–100% | logo composite + URL + plan hook | gentle wag (STATE-04), settle to idle |

Compliance rails baked into the template: process language only, no deletion/score promises, disclaimer legible ≥2s, testimonials (if ever) carry "results aren't typical."
