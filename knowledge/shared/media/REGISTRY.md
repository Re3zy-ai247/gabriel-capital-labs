# Media Registry

Every media asset committed to this knowledge tree is registered here **before** it is committed.

## Why this exists

Text will never threaten the size of this repository. Media will. Architecture §6.4 estimates the entire corpus at 70–90 MB after two decades — an estimate that holds only while binaries are controlled.

## Policy

1. **Register before committing.** An unregistered binary is a defect.
2. Record: filename, purpose, source and licence, size, who added it, date.
3. **Prefer reference over storage.** If an asset lives authoritatively elsewhere, link it.
4. **Soft budget: 50 MB total media.** Exceeding it requires a Corporate decision, not a judgement call.
5. Derived media (thumbnails, exports, re-encodes) is never committed.

## Do not

- **Do not** commit media without registering it.
- **Do not** commit derived or re-encoded media.
- **Do not** commit anything containing personal data. See Architecture §12.
