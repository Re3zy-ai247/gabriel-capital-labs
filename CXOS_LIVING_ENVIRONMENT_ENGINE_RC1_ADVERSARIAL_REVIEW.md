## 8. Mobile, reduced-motion, accessibility, and performance detail

### Mobile and reduced motion

The mobile, 360 px, 320 px, and compact-landscape cases all pass with one active chamber, zero horizontal overflow, complete navigation, and measured controls at or above 44 px. The reduced and constrained cases project Tier D/static arrival and zero running environmental animations. The reduced settled screenshot retains facility hierarchy, lighting, borders, chamber navigation, truth boundaries, and the complete active chamber; it does not appear empty or disabled.

### Accessibility

Axe reports 0 violations in every matrix case. It also reports one serious `color-contrast` rule as incomplete in every case, totaling 511 node occurrences. The recorded reasons are inability to determine the background because of gradients, pseudo-elements, or partial overlap. The repaired sample clears AA at `8.265826:1`, and representative visual review did not expose another material defect, but neither fact converts the 511 incomplete nodes into automated passes.

Target-size measurement reports 0 size failures in every sampled state. Center-point obstruction testing measured visible centers on desktop-large, desktop, tablet, reduced, and constrained. It measured zero centers on mobile, mobile-360, mobile-narrow, landscape, and reflow-200 because the sampled target centers were outside the current viewport; therefore `obstructionFailures=0` in those five cases is not comprehensive proof of zero obstruction. Successful activation paths and screenshot review mitigate the risk but do not erase this limitation.

No manual screen-reader session or external assistive-technology lab is claimed by this report.

### Performance and runtime isolation

The exact build metrics report an incremental route JavaScript increase of 2,487 gzip bytes against a 15,360-byte limit and an emitted route-owned CSS increase of 21,590 raw bytes against a 24,576-byte limit. `package.json` and the lockfile are byte-identical to baseline.

The ledger attributes no long task to candidate-owned code. It does record 10 first-party-unattributed long tasks, with a maximum duration of 109 ms, so attribution cannot fully exonerate the candidate. It records two candidate-owned long animation frames: 275.5 ms during the desktop-large Kai chamber sample and 66.7 ms during constrained static arrival; both report 0 ms blocking duration and each occurs once in the measured run. These are disclosed rather than treated as repeated blocking regressions. Production RUM and broad low-end hardware coverage are not claimed.

The local global shell also produces inherited framework noise: 24 HTTP 500 responses, 39 console errors, and 9 `nextauth.message` local-storage writes. All are classified as inherited framework behavior by the ledger. The ledger records 0 cookie writes, 0 external requests, and 0 candidate-owned non-GET requests. Candidate-owned network activity is limited to the review document and its route script in the measured run.
