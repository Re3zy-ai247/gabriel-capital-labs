Session Runtime

New files only
commit add8cd44 · lib/operatorSession.ts (411 ln) · scripts/operator-session.test.ts (290 ln) · not wired into any page yet

A pure, fully-typed derived read-model. Zero AI, zero network, zero persistence, zero schema.

  • buildOperatorSession(user) / assembleOperatorSession(inputs) produces:
    • identity: OperatorIdentity — { greetingName, altitude, onBehalfOf? }. altitude is "consumer" | "agency-owner" | "workspace", resolved from account.isAgency plus whether a client workspace cookie is present. onBehalfOf populates only at workspace altitude — the "in Elena's workspace" register.
    • yesterdayCompleted[] / todayCompleted[] — typed, capped accomplishment lists derived from the KaiEvent stream via dayWindow(now, offset), mapped through accomplishmentOf() (one case per real event kind — never synthetic).
    • interruptedWork[] — resumable states from live server data: unmailed letters and in-flight mail manifests, each carrying a resumeHref.
    • todaysPriorities[] — composes existing engines, forks neither: pickRecommendation / getKaiHomeData for consumer/workspace altitude, the agency roster ladder for agency-owner altitude.
    • sessionClose: { doneToday, remaining } — an honest rollup (see Fix Pass F3 for the post-gate correction).

Guard: scripts/operator-session.test.ts, static + logic checks. Started at 290 lines; currently 82/82 passing (extended through the fix pass, +73 lines — see Validation).
