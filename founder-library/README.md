# CreditVector Founder Library

The canonical business, product, executive, investor, and strategic documentation for **CreditVector™** by **Gabriel Capital Labs**.

This library is written for external readers: investors, enterprise customers, financial institutions, strategic partners, advisors, attorneys, future employees, and the press. It is not engineering documentation. Implementation truth lives in `.ai/` and `architecture/`; the Founder Library never duplicates it and never overrides it.

**Start with [Volume 0 — Why This Library Exists](VOLUME-00-WHY-THIS-LIBRARY-EXISTS.md).** It is the preface and governance document: document authority and scope, statuses, versioning, conflict resolution, and the permanent rules binding every volume. Read it before relying on anything else here.

## Standards

Every volume carries: Version · Status · Purpose · Intended Audience · Executive Summary · Main Content · Key Takeaways · Next Recommended Documents.

Every volume holds the same compliance bar as the product: no promised outcomes, no guaranteed deletions, no implied score improvements. CreditVector is education and software. Claims that cannot be substantiated do not appear.

## Versioning

Volumes evolve through revisions, never replacement. A published volume is not overwritten to fix a downstream inconsistency — the inconsistency is logged in [REVISION-LOG.md](REVISION-LOG.md) and resolved in a numbered revision. Presentation work (HTML editions, typesetting) advances no version. Full rules: Volume 0 §Versioning and Revision Rules.

The revision log also carries founder ratifications and open items, which are decisions rather than edits.
